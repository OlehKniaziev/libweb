# libweb
A C library for writing modern, simple web applications.

## Features
- A JSON parser and serializer
- Base64 en/decoding
- A multithreaded HTTP server and client (**NOTE**: not 100% spec compliant yet)
- HTTPS support with OpenSSL or a custom TLS implementation
- UTF8 support

## How to use it
See the `examples/` directory for short list of small self-contained examples.
